# ml-start-homework1

## Выбранный датасет
**Rain in Australia** (weatherAUS.csv) - задача бинарной классификации: предсказать, будет ли дождь на следующий день (RainTomorrow = Yes/No).  
Датасет выбран, потому что он достаточно большой (около 145 тыс. строк), содержит пропуски, разнородные признаки.

## Ссылка на данные
[Kaggle – Rain in Australia]([https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattlepackage](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package?resource=download))

## Гипотезы (сформулированы до экспериментов)
1. Логистическая регрессия с L2-регуляризацией (подбор C) покажет ROC‑AUC выше, чем без регуляризации (C=1).
2. Дерево решений начнёт переобучаться при глубине (max_depth) > 8.
3. Признак Rainfall будет самым важным для предсказания.
4. Удаление сильно коррелированных признаков улучшит качество логистической регрессии.
5. Из-за дисбаланса классов accuracy будет завышена, а F1 для класса «дождь» - низким; class_weight='balanced' повысит F1.
6. XGBoost покажет лучший ROC‑AUC по сравнению с другими моделями.
7. Стандартизация признаков (StandardScaler) улучшит качество логистической регрессии.

## Краткие результаты
- **Гипотеза 1:** Частично подтвердилась – ROC‑AUC tuned LR = 0.8830, у C=1 = 0.8828 (разница незначительна).
- **Гипотеза 2:** Подтвердилась – test accuracy перестаёт расти после глубины 8, train accuracy продолжает расти.
- **Гипотеза 3:** Подтвердилась – Rainfall оказался первым по важности.
- **Гипотеза 4:** Не подтвердилась – удаление коррелированных признаков ухудшило ROC‑AUC до 0.8802 (изначально было 0.8830).
- **Гипотеза 5:** Подтвердилась – после применения class_weight='balanced' F1 для класса «дождь» вырос с 0.52 до 0.60.
- **Гипотеза 6:** Подтвердилась – XGBoost дал ROC‑AUC = 0.8947, выше всех остальных.
- **Гипотеза 7:** Подтвердилась – без масштабирования ROC‑AUC LR = 0.87, с масштабированием = 0.8830.

Все эксперименты и код доступны в `research.ipynb`.
